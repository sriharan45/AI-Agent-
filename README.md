# 👋 I am here to help you

A sleek, interactive AI Agent with live world clocks, precision math, and mind-refreshing facts. Built with Python and Streamlit.

---

## ✨ What this Agent can do

* 🕒 **World Clock:** Live real-time clock for USA (New York & California), India, UK, Dubai, Japan, and more.
* 🧮 **Instant Math:** Accurate arithmetic without guessing or hallucinations.
* 🌿 **Mind-Refreshing Facts:** Intriguing science, nature, and space facts to brighten your day.
* 📝 **Quick Notes:** Easy note-taking on the fly.
